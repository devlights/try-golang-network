# 第3章: UDP通信の実装

## Go言語バージョン: Go 1.22（2024年10月時点での最新安定版）

UDP（User Datagram Protocol）はTCPと並ぶ重要なトランスポート層プロトコルです。コネクションレス、軽量、高速という特徴を持ち、リアルタイム性が求められるアプリケーションに適しています。この章では、Go言語でのUDP通信の実装について実務レベルの知識とスキルを身につけていきましょう。

## 1. UDPの基本概念と特性

UDPはTCPと異なり、以下の特性を持ちます：

- **コネクションレス**: 通信前に接続確立が不要
- **信頼性がない**: パケットの到達保証、順序保証、重複排除がない
- **低オーバーヘッド**: ヘッダサイズが小さく(8バイト)、処理が軽量
- **高速**: 確認応答やフロー制御がないため、TCPより高速
- **メッセージ指向**: データグラムという単位で送受信

### 適用シナリオ

UDPが適している用途：
- DNS, DHCP, NTPなどのプロトコル
- ビデオストリーミング、音声通話（VoIP）
- オンラインゲーム
- IoTデバイスからの軽量データ送信
- メトリクス収集システム

## 2. UDPサーバーの実装

UDPサーバーの基本実装を見ていきましょう。

```go
// Go 1.22
package main

import (
	"fmt"
	"log"
	"net"
	"os"
	"os/signal"
	"sync"
	"syscall"
	"time"
)

const (
	udpBufferSize  = 1024
	readTimeout    = 5 * time.Second
	writeTimeout   = 5 * time.Second
	serverAddr     = ":8053" // UDPサーバーのアドレス
	logTimeFormat  = "2006-01-02 15:04:05.000"
)

// SafeLogger はスレッドセーフなロガー
type SafeLogger struct {
	mu  sync.Mutex
	log *log.Logger
}

func (sl *SafeLogger) Printf(format string, v ...interface{}) {
	sl.mu.Lock()
	defer sl.mu.Unlock()
	sl.log.Printf(format, v...)
}

func main() {
	// ロガーの設定
	logger := &SafeLogger{
		log: log.New(os.Stdout, "[UDPサーバー] ", log.LstdFlags),
	}

	// UDPアドレスの解決
	addr, err := net.ResolveUDPAddr("udp", serverAddr)
	if err != nil {
		logger.Printf("アドレス解決エラー: %v", err)
		os.Exit(1)
	}

	// UDPリスナーの作成
	conn, err := net.ListenUDP("udp", addr)
	if err != nil {
		logger.Printf("UDPリスニングエラー: %v", err)
		os.Exit(1)
	}
	defer conn.Close()

	logger.Printf("UDPサーバーが %s で起動しました", addr)

	// グレースフルシャットダウンの設定
	sigCh := make(chan os.Signal, 1)
	signal.Notify(sigCh, syscall.SIGINT, syscall.SIGTERM)
	
	// 終了通知用チャネル
	done := make(chan struct{})
	
	// 受信処理
	go func() {
		buffer := make([]byte, udpBufferSize)
		for {
			select {
			case <-done:
				return
			default:
				// 読み取りタイムアウトの設定
				if err := conn.SetReadDeadline(time.Now().Add(readTimeout)); err != nil {
					logger.Printf("読み取りタイムアウト設定エラー: %v", err)
					continue
				}

				// データグラムの受信
				n, raddr, err := conn.ReadFromUDP(buffer)
				if err != nil {
					if netErr, ok := err.(net.Error); ok && netErr.Timeout() {
						// タイムアウトは正常なケース
						continue
					}
					logger.Printf("データ受信エラー: %v", err)
					continue
				}

				// 受信データの処理
				message := string(buffer[:n])
				logger.Printf("クライアント %s からのメッセージ: %s", raddr, message)

				// 送信タイムアウトの設定
				if err := conn.SetWriteDeadline(time.Now().Add(writeTimeout)); err != nil {
					logger.Printf("書き込みタイムアウト設定エラー: %v", err)
					continue
				}

				// レスポンスの送信
				response := fmt.Sprintf("エコー: %s", message)
				if _, err := conn.WriteToUDP([]byte(response), raddr); err != nil {
					logger.Printf("レスポンス送信エラー: %v", err)
				}
			}
		}
	}()

	// シグナルを待機
	<-sigCh
	logger.Printf("シャットダウンシグナルを受信しました")
	
	// 終了通知
	close(done)
	
	// 全ての処理が完了するまで少し待機
	time.Sleep(100 * time.Millisecond)
	logger.Printf("UDPサーバーをシャットダウンしました")
}
```

### 業務レベルでの考慮点

1. **バッファサイズ**: UDPデータグラムの最大サイズは理論上64KBですが、実際にはMTU（Maximum Transmission Unit）の制限があります。IPv4では通常1500バイト前後です。大きなデータグラムは断片化される可能性があり、パフォーマンスに影響します。

2. **タイムアウト処理**: UDPはコネクションレスなので、TCP接続のように自然にタイムアウトしません。明示的なタイムアウト処理が必要です。

3. **エラー処理**: ネットワークエラーは一時的なものが多いため、適切なリトライロジックが重要です。

4. **スレッドセーフ**: 並行処理環境では、共有リソース（ロガーなど）へのアクセスは適切に保護する必要があります。

## 3. UDPクライアントの実装

UDPクライアントの基本実装を見ていきましょう。

```go
// Go 1.22
package main

import (
	"context"
	"flag"
	"fmt"
	"log"
	"net"
	"os"
	"time"
)

const (
	defaultServerAddr = "localhost:8053"
	defaultTimeout    = 5 * time.Second
	udpBufferSize     = 1024
)

func main() {
	// コマンドライン引数の処理
	serverAddr := flag.String("server", defaultServerAddr, "UDPサーバーアドレス")
	message := flag.String("message", "Hello, UDP!", "送信するメッセージ")
	timeout := flag.Duration("timeout", defaultTimeout, "タイムアウト期間")
	flag.Parse()

	// コンテキストの作成（タイムアウト付き）
	ctx, cancel := context.WithTimeout(context.Background(), *timeout)
	defer cancel()

	// UDPクライアントの実行
	if err := sendUDPMessage(ctx, *serverAddr, *message); err != nil {
		log.Fatalf("エラー: %v", err)
	}
}

func sendUDPMessage(ctx context.Context, serverAddr, message string) error {
	// UDPアドレスの解決
	raddr, err := net.ResolveUDPAddr("udp", serverAddr)
	if err != nil {
		return fmt.Errorf("サーバーアドレス解決エラー: %w", err)
	}

	// UDPコネクションの作成
	conn, err := net.DialUDP("udp", nil, raddr)
	if err != nil {
		return fmt.Errorf("UDP接続エラー: %w", err)
	}
	defer conn.Close()

	// 送信タイムアウトの設定
	deadline, ok := ctx.Deadline()
	if ok {
		if err := conn.SetWriteDeadline(deadline); err != nil {
			return fmt.Errorf("書き込みタイムアウト設定エラー: %w", err)
		}
	}

	// メッセージの送信
	fmt.Printf("送信メッセージ: %s\n", message)
	_, err = conn.Write([]byte(message))
	if err != nil {
		return fmt.Errorf("メッセージ送信エラー: %w", err)
	}

	// 受信タイムアウトの設定
	if ok {
		if err := conn.SetReadDeadline(deadline); err != nil {
			return fmt.Errorf("読み取りタイムアウト設定エラー: %w", err)
		}
	}

	// レスポンスの受信
	buffer := make([]byte, udpBufferSize)
	n, _, err := conn.ReadFromUDP(buffer)
	if err != nil {
		return fmt.Errorf("レスポンス受信エラー: %w", err)
	}

	// レスポンスの表示
	response := string(buffer[:n])
	fmt.Printf("受信レスポンス: %s\n", response)

	return nil
}
```

### DialUDP vs WriteToUDP

Goでは2つのUDP通信方法があります：

1. **DialUDP + Write/Read**: 特定の宛先との通信に特化。コネクション指向のAPIに近い使い方が可能。
2. **ListenUDP + WriteToUDP/ReadFromUDP**: 複数の宛先と通信する場合に適しています。

業務上の選択基準：
- 単一の宛先との通信: `DialUDP` が簡潔でエラー処理も容易
- 複数クライアントとの通信（サーバー側）: `ListenUDP` が適切

## 4. 信頼性の確保とフロー制御

UDPは信頼性を保証しないため、アプリケーション層で実装する必要があります。

### 信頼性向上の一般的な手法

1. **シーケンス番号**: 各パケットに連番を付与して順序保証と重複検出を実現
2. **確認応答（ACK）**: 受信側からの受信確認
3. **タイムアウトと再送**: 確認応答がない場合の再送メカニズム
4. **ウィンドウベースのフロー制御**: 送信レートの調整

以下は簡易的な信頼性UDPプロトコルの実装例です：

```go
// Go 1.22
package main

import (
	"encoding/binary"
	"fmt"
	"log"
	"net"
	"sync"
	"time"
)

const (
	maxRetries      = 3
	ackTimeout      = 500 * time.Millisecond
	headerSize      = 8 // シーケンス番号(4) + フラグ(4)
	maxPayloadSize  = 1472 - headerSize // 一般的なMTU(1500) - IP(20) - UDP(8) - ヘッダ(8)
)

// パケットタイプ
const (
	flagData uint32 = iota
	flagAck
)

// 信頼性UDPクライアント
type ReliableUDPClient struct {
	conn         *net.UDPConn
	serverAddr   *net.UDPAddr
	nextSeqNum   uint32
	pendingAcks  map[uint32]chan struct{}
	mu           sync.Mutex
	timeout      time.Duration
	maxRetries   int
}

// 新しいクライアントを作成
func NewReliableUDPClient(serverAddr string, timeout time.Duration, maxRetries int) (*ReliableUDPClient, error) {
	raddr, err := net.ResolveUDPAddr("udp", serverAddr)
	if err != nil {
		return nil, fmt.Errorf("サーバーアドレス解決エラー: %w", err)
	}

	conn, err := net.DialUDP("udp", nil, raddr)
	if err != nil {
		return nil, fmt.Errorf("UDP接続エラー: %w", err)
	}

	return &ReliableUDPClient{
		conn:        conn,
		serverAddr:  raddr,
		nextSeqNum:  0,
		pendingAcks: make(map[uint32]chan struct{}),
		timeout:     timeout,
		maxRetries:  maxRetries,
	}, nil
}

// クライアントを閉じる
func (c *ReliableUDPClient) Close() error {
	return c.conn.Close()
}

// パケットにヘッダーを追加
func encodePacket(seqNum uint32, flag uint32, payload []byte) []byte {
	packet := make([]byte, headerSize+len(payload))
	binary.BigEndian.PutUint32(packet[0:4], seqNum)
	binary.BigEndian.PutUint32(packet[4:8], flag)
	copy(packet[headerSize:], payload)
	return packet
}

// パケットからヘッダーとペイロードを抽出
func decodePacket(packet []byte) (seqNum uint32, flag uint32, payload []byte) {
	if len(packet) < headerSize {
		return 0, 0, nil
	}
	seqNum = binary.BigEndian.Uint32(packet[0:4])
	flag = binary.BigEndian.Uint32(packet[4:8])
	payload = packet[headerSize:]
	return
}

// ACK受信用ゴルーチン
func (c *ReliableUDPClient) receiveAcks() {
	buffer := make([]byte, 2048)
	for {
		n, _, err := c.conn.ReadFromUDP(buffer)
		if err != nil {
			if netErr, ok := err.(net.Error); ok && netErr.Timeout() {
				continue
			}
			log.Printf("ACK受信エラー: %v", err)
			continue
		}

		seqNum, flag, _ := decodePacket(buffer[:n])
		if flag == flagAck {
			c.mu.Lock()
			if ch, ok := c.pendingAcks[seqNum]; ok {
				close(ch)
				delete(c.pendingAcks, seqNum)
			}
			c.mu.Unlock()
		}
	}
}

// 信頼性のあるメッセージ送信
func (c *ReliableUDPClient) SendReliable(payload []byte) error {
	// 大きなペイロードの分割処理は省略

	c.mu.Lock()
	seqNum := c.nextSeqNum
	c.nextSeqNum++
	ackCh := make(chan struct{})
	c.pendingAcks[seqNum] = ackCh
	c.mu.Unlock()

	packet := encodePacket(seqNum, flagData, payload)

	// タイムアウトと再送のロジック
	for retry := 0; retry < c.maxRetries; retry++ {
		if retry > 0 {
			log.Printf("パケット #%d の再送 (試行 %d/%d)", seqNum, retry+1, c.maxRetries)
		}

		_, err := c.conn.Write(packet)
		if err != nil {
			return fmt.Errorf("パケット送信エラー: %w", err)
		}

		// ACKを待機
		select {
		case <-ackCh:
			return nil // 成功
		case <-time.After(c.timeout):
			// タイムアウト、再送
		}
	}

	c.mu.Lock()
	delete(c.pendingAcks, seqNum)
	c.mu.Unlock()

	return fmt.Errorf("最大再送回数に達しました")
}

func main() {
	// 使用例
	client, err := NewReliableUDPClient("localhost:8053", ackTimeout, maxRetries)
	if err != nil {
		log.Fatalf("クライアント初期化エラー: %v", err)
	}
	defer client.Close()

	// ACK受信ゴルーチンを開始
	go client.receiveAcks()

	// メッセージ送信
	message := "これは信頼性のあるUDPメッセージです"
	if err := client.SendReliable([]byte(message)); err != nil {
		log.Fatalf("送信エラー: %v", err)
	}
	
	log.Println("メッセージが正常に送信されました")
}
```

このコードは概念的な例であり、実際の実装では以下の点も考慮する必要があります：

- 輻輳制御（ネットワーク混雑時の送信レート調整）
- スライディングウィンドウ（複数パケットの効率的な送信）
- 選択的再送（失われたパケットのみを再送）
- バッファ管理（メモリ使用量の最適化）

### 既存の実装の活用

実務では、信頼性UDPを自前で実装するよりも、以下のような既存のソリューションを検討することも重要です：

## 5. マルチキャストとブロードキャスト

### マルチキャスト

マルチキャストは特定のグループに属するホストにのみパケットを送信する方法です。

```go
// Go 1.22
package main

import (
	"flag"
	"log"
	"net"
	"os"
	"os/signal"
	"syscall"
	"time"
)

var (
	interfaceName = flag.String("interface", "", "マルチキャストに使用するネットワークインターフェース名")
	groupAddr     = flag.String("group", "224.0.0.1:9999", "マルチキャストグループアドレス")
	mode          = flag.String("mode", "receive", "モード: 'send' または 'receive'")
	message       = flag.String("message", "マルチキャストテストメッセージ", "送信するメッセージ")
	interval      = flag.Duration("interval", 1*time.Second, "送信間隔")
)

func main() {
	flag.Parse()

	// シグナルハンドリング
	sigCh := make(chan os.Signal, 1)
	signal.Notify(sigCh, syscall.SIGINT, syscall.SIGTERM)
	doneCh := make(chan struct{})

	if *mode == "send" {
		go runSender(doneCh)
	} else {
		go runReceiver(doneCh)
	}

	// 終了シグナルを待機
	<-sigCh
	close(doneCh)
	log.Println("プログラムを終了します")
}

// インターフェースの検索
func findInterface() (*net.Interface, error) {
	if *interfaceName != "" {
		return net.InterfaceByName(*interfaceName)
	}

	// デフォルトではシステムがルーティングに使用するインターフェースを探す
	interfaces, err := net.Interfaces()
	if err != nil {
		return nil, err
	}

	for _, intf := range interfaces {
		if intf.Flags&net.FlagUp == 0 {
			continue // インターフェースがダウンしている
		}
		if intf.Flags&net.FlagLoopback != 0 {
			continue // ループバックインターフェース
		}
		if intf.Flags&net.FlagMulticast == 0 {
			continue // マルチキャスト非対応
		}

		addrs, err := intf.Addrs()
		if err != nil {
			continue
		}

		for _, addr := range addrs {
			if ipnet, ok := addr.(*net.IPNet); ok && !ipnet.IP.IsLoopback() {
				if ipnet.IP.To4() != nil {
					return &intf, nil // IPv4アドレスを持つインターフェースを使用
				}
			}
		}
	}

	return nil, fmt.Errorf("適切なネットワークインターフェースが見つかりません")
}

func runSender(done <-chan struct{}) {
	// インターフェースの検索
	intf, err := findInterface()
	if err != nil {
		log.Fatalf("インターフェース検索エラー: %v", err)
	}
	log.Printf("インターフェース %s (index: %d) を使用します", intf.Name, intf.Index)

	// グループアドレスの解決
	gaddr, err := net.ResolveUDPAddr("udp", *groupAddr)
	if err != nil {
		log.Fatalf("アドレス解決エラー: %v", err)
	}

	// UDPコネクションの作成
	conn, err := net.ListenUDP("udp", &net.UDPAddr{IP: net.IPv4zero, Port: 0})
	if err != nil {
		log.Fatalf("UDPリスニングエラー: %v", err)
	}
	defer conn.Close()

	// ループ変数
	ticker := time.NewTicker(*interval)
	defer ticker.Stop()

	// メッセージ送信ループ
	for {
		select {
		case <-ticker.C:
			// マルチキャストメッセージを送信
			if _, err := conn.WriteTo([]byte(*message), gaddr); err != nil {
				log.Printf("送信エラー: %v", err)
			} else {
				log.Printf("メッセージをグループ %s に送信しました", gaddr)
			}
		case <-done:
			return
		}
	}
}

func runReceiver(done <-chan struct{}) {
	// インターフェースの検索
	intf, err := findInterface()
	if err != nil {
		log.Fatalf("インターフェース検索エラー: %v", err)
	}
	log.Printf("インターフェース %s (index: %d) を使用します", intf.Name, intf.Index)

	// グループアドレスの解決
	gaddr, err := net.ResolveUDPAddr("udp", *groupAddr)
	if err != nil {
		log.Fatalf("アドレス解決エラー: %v", err)
	}

	// UDPコネクションの作成
	conn, err := net.ListenMulticastUDP("udp", intf, gaddr)
	if err != nil {
		log.Fatalf("マルチキャストリスニングエラー: %v", err)
	}
	defer conn.Close()

	// バッファサイズの設定
	if err := conn.SetReadBuffer(1024 * 1024); err != nil {
		log.Printf("読み取りバッファ設定エラー: %v", err)
	}

	log.Printf("マルチキャストグループ %s をリッスンしています...", gaddr)

	// 受信バッファ
	buffer := make([]byte, 1024)

	// 読み取りデッドラインの設定
	if err := conn.SetReadDeadline(time.Now().Add(1 * time.Second)); err != nil {
		log.Fatalf("読み取りデッドライン設定エラー: %v", err)
	}

	// 受信ループ
	for {
		select {
		case <-done:
			return
		default:
			// 読み取りデッドラインの更新
			if err := conn.SetReadDeadline(time.Now().Add(1 * time.Second)); err != nil {
				log.Printf("読み取りデッドライン更新エラー: %v", err)
				continue
			}

			// パケットの受信
			n, src, err := conn.ReadFromUDP(buffer)
			if err != nil {
				if netErr, ok := err.(net.Error); ok && netErr.Timeout() {
					// タイムアウトは無視
					continue
				}
				log.Printf("受信エラー: %v", err)
				continue
			}

			// メッセージの処理
			log.Printf("%s からメッセージを受信: %s", src, string(buffer[:n]))
		}
	}
}
```

### マルチキャストの技術的制約

1. **ネットワーク対応**: すべてのネットワーク機器がマルチキャストに対応しているわけではありません。特にインターネット経由のマルチキャストは通常制限されています。

2. **TTL設定**: マルチキャストの到達範囲はTTL（Time To Live）値で制限されます。
   - TTL=1: 同一サブネット内のみ
   - TTL>1: ルーターを越えた範囲（ネットワーク設定に依存）

3. **OSとハードウェアの制限**: プラットフォームによってマルチキャスト実装が異なる場合があります。

### ブロードキャスト

ブロードキャストはサブネット内のすべてのホストにパケットを送信する方法です。

```go
// Go 1.22
package main

import (
	"flag"
	"log"
	"net"
	"os"
	"os/signal"
	"syscall"
	"time"
)

var (
	broadcastAddr = flag.String("broadcast", "255.255.255.255:9999", "ブロードキャストアドレス")
	mode          = flag.String("mode", "receive", "モード: 'send' または 'receive'")
	message       = flag.String("message", "ブロードキャストテストメッセージ", "送信するメッセージ")
	interval      = flag.Duration("interval", 1*time.Second, "送信間隔")
)

func main() {
	flag.Parse()

	// シグナルハンドリング
	sigCh := make(chan os.Signal, 1)
	signal.Notify(sigCh, syscall.SIGINT, syscall.SIGTERM)
	doneCh := make(chan struct{})

	if *mode == "send" {
		go runBroadcastSender(doneCh)
	} else {
		go runBroadcastReceiver(doneCh)
	}

	// 終了シグナルを待機
	<-sigCh
	close(doneCh)
	log.Println("プログラムを終了します")
}

func runBroadcastSender(done <-chan struct{}) {
	// アドレスの解決
	addr, err := net.ResolveUDPAddr("udp", *broadcastAddr)
	if err != nil {
		log.Fatalf("アドレス解決エラー: %v", err)
	}

	// UDPコネクションの作成
	conn, err := net.DialUDP("udp", nil, addr)
	if err != nil {
		log.Fatalf("UDP接続エラー: %v", err)
	}
	defer conn.Close()

	// ブロードキャストの有効化
	if err := conn.SetWriteBuffer(1024 * 1024); err != nil {
		log.Printf("書き込みバッファ設定エラー: %v", err)
	}

	// ループ変数
	ticker := time.NewTicker(*interval)
	defer ticker.Stop()

	// メッセージ送信ループ
	for {
		select {
		case <-ticker.C:
			// ブロードキャストメッセージを送信
			if _, err := conn.Write([]byte(*message)); err != nil {
				log.Printf("送信エラー: %v", err)
			} else {
				log.Printf("メッセージをブロードキャストアドレス %s に送信しました", addr)
			}
		case <-done:
			return
		}
	}
}

func runBroadcastReceiver(done <-chan struct{}) {
	// アドレスの解決（ポート部分のみ使用）
	laddr, err := net.ResolveUDPAddr("udp", ":"+*broadcastAddr[net.JoinHostPort("", *broadcastAddr)])
	if err != nil {
		log.Fatalf("アドレス解決エラー: %v", err)
	}

	// UDP接続のリスニング
	conn, err := net.ListenUDP("udp", laddr)
	if err != nil {
		log.Fatalf("UDPリスニングエラー: %v", err)
	}
	defer conn.Close()

	// バッファサイズの設定
	if err := conn.SetReadBuffer(1024 * 1024); err != nil {
		log.Printf("読み取りバッファ設定エラー: %v", err)
	}

	log.Printf("ブロードキャストを %s でリッスンしています...", laddr)

	// 受信バッファ
	buffer := make([]byte, 1024)

	// 読み取りデッドラインの設定
	if err := conn.SetReadDeadline(time.Now().Add(1 * time.Second)); err != nil {
		log.Fatalf("読み取りデッドライン設定エラー: %v", err)
	}

	// 受信ループ
	for {
		select {
		case <-done:
			return
		default:
			// 読み取りデッドラインの更新
			if err := conn.SetReadDeadline(time.Now().Add(1 * time.Second)); err != nil {
				log.Printf("読み取りデッドライン更新エラー: %v", err)
				continue
			}

			// パケットの受信
			n, src, err := conn.ReadFromUDP(buffer)
			if err != nil {
				if netErr, ok := err.(net.Error); ok && netErr.Timeout() {
					// タイムアウトは無視
					continue
				}
				log.Printf("受信エラー: %v", err)
				continue
			}

			// メッセージの処理
			log.Printf("%s からメッセージを受信: %s", src, string(buffer[:n]))
		}
	}
}
```

### ブロードキャストの技術的制約

1. **範囲制限**: ブロードキャストはサブネット内のみに制限されます。
2. **ネットワーク負荷**: すべてのホストがパケットを処理するため、ネットワーク負荷が高くなります。
3. **セキュリティ制限**: 多くの環境でブロードキャストトラフィックはファイアウォールで制限されています。

## 6. エラー処理と再送戦略

UDPの信頼性を向上させるための再送戦略は、アプリケーションの要件によって異なります。

### 一般的な再送戦略

1. **固定間隔再送**
   - 最もシンプルな方法
   - 一定の間隔で再送を繰り返す
   - ネットワーク混雑時にさらなる輻輳を引き起こす可能性

2. **指数バックオフ**
   - 再送間隔を指数関数的に増加（例: 100ms, 200ms, 400ms, ...）
   - ネットワーク輻輳時に優れた性能
   - TCP再送戦略の基本アプローチ

3. **ジッター付き再送**
   - 再送間隔にランダム変動（ジッター）を追加
   - 「再送の嵐」を防止
   - 分散システムでよく使用される

以下はジッター付き指数バックオフを実装した例です：

```go
// Go 1.22
package main

import (
	"math/rand"
	"time"
)

// 再送戦略インターフェース
type RetryStrategy interface {
	// 次の再送までの待機時間を計算
	NextBackoff(retry int) time.Duration
	// 最大再送回数を取得
	MaxRetries() int
}

// 指数バックオフ戦略（ジッター付き）
type ExponentialBackoff struct {
	baseDelay      time.Duration // 基本待機時間
	maxDelay       time.Duration // 最大待機時間
	maxRetries     int           // 最大再送回数
	jitterPercent  float64       // ジッター率 (0.0-1.0)
	rand           *rand.Rand    // 乱数生成器
}

// 新しい指数バックオフ戦略を作成
func NewExponentialBackoff(
	baseDelay time.Duration,
	maxDelay time.Duration,
	maxRetries int,
	jitterPercent float64,
) *ExponentialBackoff {
	src := rand.NewSource(time.Now().UnixNano())
	return &ExponentialBackoff{
		baseDelay:     baseDelay,
		maxDelay:      maxDelay,
		maxRetries:    maxRetries,
		jitterPercent: jitterPercent,
		rand:          rand.New(src),
	}
}

// 次の再送までの待機時間を計算
func (eb *ExponentialBackoff) NextBackoff(retry int) time.Duration {
	// 指数バックオフ計算
	// retry=0 の場合は最初の送信なのでバックオフなし
	if retry <= 0 {
		return 0
	}
	
	// 2^retry * baseDelay （例: retry=3 なら 2^3 * baseDelay = 8 * baseDelay）
	backoff := eb.baseDelay
	for i := 0; i < retry; i++ {
		backoff *= 2
		if backoff > eb.maxDelay {
			backoff = eb.maxDelay
			break
		}
	}
	
	// ジッターの追加（例: jitterPercent=0.2 なら ±20%のランダム変動）
	if eb.jitterPercent > 0 {
		jitter := float64(backoff) * eb.jitterPercent
		jitterDuration := time.Duration(eb.rand.Float64()*jitter*2 - jitter)
		backoff += jitterDuration
	}
	
	// 最小1msを保証
	if backoff < time.Millisecond {
		backoff = time.Millisecond
	}
	
	return backoff
}

// 最大再送回数を取得
func (eb *ExponentialBackoff) MaxRetries() int {
	return eb.maxRetries
}

// 再送ロジックの例
func SendWithRetry(data []byte, strategy RetryStrategy) error {
	var lastErr error
	
	for retry := 0; retry <= strategy.MaxRetries(); retry++ {
		// 再送前のバックオフ
		backoff := strategy.NextBackoff(retry)
		if backoff > 0 {
			time.Sleep(backoff)
		}
		
		// パケット送信処理（実装省略）
		err := sendUDPPacket(data)
		if err == nil {
			return nil // 成功
		}
		
		lastErr = err
	}
	
	return fmt.Errorf("最大再送回数に到達: %w", lastErr)
}

// 実際のUDPパケット送信（この実装は簡略化）
func sendUDPPacket(data []byte) error {
	// 実際の送信処理
	return nil
}

func main() {
	// 使用例
	strategy := NewExponentialBackoff(
		100*time.Millisecond, // 基本待機時間
		5*time.Second,        // 最大待機時間
		5,                    // 最大再送回数
		0.2,                  // ジッター率 (20%)
	)
	
	data := []byte("テストメッセージ")
	if err := SendWithRetry(data, strategy); err != nil {
		log.Fatalf("送信エラー: %v", err)
	}
}
```

### 業務レベルでのエラーハンドリング

実務では、以下の点も考慮する必要があります：

1. **エラーの分類**:
   - 一時的エラー（再送で解決可能）
   - 永続的エラー（再送しても解決しない）
   - リソース制約エラー（バッファ不足など）

2. **サーキットブレーカー**:
   - 継続的な失敗を検出してシステムを保護
   - 一定期間後に自動復旧を試みる

3. **グレースフルデグラデーション**:
   - ネットワーク品質低下時にサービス品質を段階的に落とす
   - 例: ビデオ通話でのビットレート動的調整

4. **テレメトリとモニタリング**:
   - 再送率、パケット損失率、遅延などの指標を測定
   - 閾値ベースのアラート設定

## まとめ: UDP通信実装のベストプラクティス

1. **適切なユースケースの選択**:
   - リアルタイム性が重要な場合はUDP
   - 信頼性が重要な場合はTCPまたは信頼性UDPの実装

2. **バッファサイズの最適化**:
   - MTU制限を考慮したバッファサイズ設定
   - 大きなデータの分割送信

3. **タイムアウト管理**:
   - 明示的なタイムアウト設定
   - コンテキストを使用したキャンセル処理

4. **エラーハンドリング**:
   - 適切な再送戦略の実装
   - 一時的エラーと永続的エラーの区別

5. **セキュリティ考慮事項**:
   - 認証と暗号化の実装
   - DoS攻撃からの保護

6. **テスト戦略**:
   - 様々なネットワーク条件でのテスト
   - カオスエンジニアリング（パケット損失、遅延などをシミュレート）

7. **モニタリング**:
   - パケット損失率、遅延、ジッター、スループットの監視
   - 異常検出と自動修復

業務レベルのUDP実装では、これらの点を総合的に考慮し、アプリケーションの要件に応じた最適なアプローチを選択することが重要です。
