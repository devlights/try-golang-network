# 第5章: プロトコル設計と実装

Go言語バージョン: Go 1.22（2024年10月時点での最新安定版）

## 1. カスタムプロトコルの設計原則

### プロトコル設計の基本原則

カスタムプロトコルを設計する際は、以下の原則を考慮することが重要です：

1. **明確性と単純性**：理解と実装が容易なプロトコルが長期的には保守性に優れます
2. **拡張性**：将来的な要件変更に対応できるよう設計します
3. **バージョニング**：互換性を維持しながら進化できる仕組みを組み込みます
4. **効率性**：データ転送量とCPU使用率を最適化します
5. **堅牢性**：不正な入力やネットワーク障害に対する耐性を持たせます
6. **セキュリティ**：データの機密性、完全性、認証を考慮します

### プロトコル仕様の文書化

業務レベルのプロトコル設計では、詳細な仕様書の作成が不可欠です：

```go
/*
プロトコル仕様例：MyCustomProtocol v1.0

1. 概要:
   簡潔で効率的なバイナリプロトコル、クライアント/サーバー間通信用

2. メッセージ構造:
   Header (8バイト):
     - Magic Number (2バイト): 0xAB 0xCD
     - プロトコルバージョン (1バイト): 現在は0x01
     - メッセージタイプ (1バイト): コマンド種別
     - ペイロード長 (4バイト): 最大4GBのペイロード
   Payload (可変長):
     - 最大4GBのアプリケーションデータ

3. メッセージタイプ:
   0x01: 認証要求
   0x02: 認証応答
   0x03: データ要求
   0x04: データ応答
   0xFF: エラー

4. エラー処理:
   エラーメッセージのペイロードは以下の形式:
   - エラーコード (2バイト)
   - エラーメッセージ (残りのペイロード)
*/
```

### 設計パターンの選択

プロトコル設計では、以下のパターンから適切なものを選ぶことが重要です：

1. **リクエスト-レスポンス型**：クライアントからのリクエストに対してサーバーが応答
2. **パブリッシュ-サブスクライブ型**：発行者がメッセージを送信し、複数の購読者が受信
3. **ストリーミング型**：連続的なデータ転送
4. **RPC（Remote Procedure Call）型**：リモート関数呼び出し

### サンプルコード：プロトコル定義

以下は業務レベルでのプロトコル定義の例です：

```go
// protocol.go
package myprotocol

import (
	"encoding/binary"
	"errors"
	"fmt"
	"io"
)

// プロトコル定数
const (
	MagicNumber      uint16 = 0xABCD
	CurrentVersion   uint8  = 0x01
	HeaderSize       int    = 8
	MaxPayloadSize   int    = 4 * 1024 * 1024 * 1024 // 4GB
	DefaultBufferSize int   = 4096
)

// メッセージタイプ
const (
	TypeAuthRequest  uint8 = 0x01
	TypeAuthResponse uint8 = 0x02
	TypeDataRequest  uint8 = 0x03
	TypeDataResponse uint8 = 0x04
	TypeError        uint8 = 0xFF
)

// エラーコード
const (
	ErrCodeInvalidProtocol uint16 = 1000
	ErrCodeInvalidVersion  uint16 = 1001
	ErrCodePayloadTooLarge uint16 = 1002
	ErrCodeUnauthorized    uint16 = 2000
	ErrCodeServerError     uint16 = 5000
)

// 既知のエラー
var (
	ErrInvalidMagicNumber = errors.New("無効なマジックナンバー")
	ErrInvalidVersion     = errors.New("サポートされていないプロトコルバージョン")
	ErrPayloadTooLarge    = errors.New("ペイロードサイズが上限を超えています")
	ErrIncompleteHeader   = errors.New("不完全なヘッダー")
	ErrInvalidMessageType = errors.New("無効なメッセージタイプ")
)

// Header はプロトコルヘッダを表します
type Header struct {
	MagicNumber    uint16
	Version        uint8
	MessageType    uint8
	PayloadLength  uint32
}

// Message はプロトコルメッセージを表します
type Message struct {
	Header  Header
	Payload []byte
}

// NewMessage は新しいメッセージを作成します
func NewMessage(messageType uint8, payload []byte) (*Message, error) {
	if len(payload) > MaxPayloadSize {
		return nil, ErrPayloadTooLarge
	}

	return &Message{
		Header: Header{
			MagicNumber:    MagicNumber,
			Version:        CurrentVersion,
			MessageType:    messageType,
			PayloadLength:  uint32(len(payload)),
		},
		Payload: payload,
	}, nil
}

// NewErrorMessage はエラーメッセージを作成します
func NewErrorMessage(errorCode uint16, errorMsg string) (*Message, error) {
	payload := make([]byte, 2+len(errorMsg))
	binary.BigEndian.PutUint16(payload[0:2], errorCode)
	copy(payload[2:], []byte(errorMsg))
	
	return NewMessage(TypeError, payload)
}

// ErrorInfo はエラーメッセージから情報を抽出します
func (m *Message) ErrorInfo() (code uint16, message string, err error) {
	if m.Header.MessageType != TypeError || len(m.Payload) < 2 {
		return 0, "", fmt.Errorf("エラーメッセージではありません")
	}
	
	code = binary.BigEndian.Uint16(m.Payload[0:2])
	message = string(m.Payload[2:])
	return code, message, nil
}

// Validate はメッセージが有効かどうかを確認します
func (m *Message) Validate() error {
	if m.Header.MagicNumber != MagicNumber {
		return ErrInvalidMagicNumber
	}
	if m.Header.Version != CurrentVersion {
		return ErrInvalidVersion
	}
	if int(m.Header.PayloadLength) > MaxPayloadSize {
		return ErrPayloadTooLarge
	}
	return nil
}
```

## 2. バイナリプロトコルの実装

バイナリプロトコルは効率的なデータ転送に適しており、通信速度とリソース使用率の最適化が求められる場面で重要です。

### バイナリプロトコルの利点

1. **データサイズの効率性**：テキストベースプロトコルより30-50%小さいデータサイズ
2. **解析速度**：バイナリ形式はテキスト解析より最大10倍高速
3. **明確な型定義**：データ型が明示的に定義される

### エンディアン問題への対処

異なるシステム間でのバイトオーダーの違いに注意する必要があります：

```go
// encoding.go
package myprotocol

import (
	"encoding/binary"
	"io"
)

// エンディアン形式の定義（業務での標準化）
var byteOrder = binary.BigEndian

// ReadHeader はリーダーからヘッダーを読み込みます
func ReadHeader(r io.Reader) (Header, error) {
	headerBuf := make([]byte, HeaderSize)
	
	if _, err := io.ReadFull(r, headerBuf); err != nil {
		if err == io.EOF || err == io.ErrUnexpectedEOF {
			return Header{}, ErrIncompleteHeader
		}
		return Header{}, err
	}
	
	h := Header{
		MagicNumber:   byteOrder.Uint16(headerBuf[0:2]),
		Version:       headerBuf[2],
		MessageType:   headerBuf[3],
		PayloadLength: byteOrder.Uint32(headerBuf[4:8]),
	}
	
	return h, nil
}

// WriteHeader はヘッダーをライターに書き込みます
func WriteHeader(w io.Writer, h Header) error {
	headerBuf := make([]byte, HeaderSize)
	
	byteOrder.PutUint16(headerBuf[0:2], h.MagicNumber)
	headerBuf[2] = h.Version
	headerBuf[3] = h.MessageType
	byteOrder.PutUint32(headerBuf[4:8], h.PayloadLength)
	
	_, err := w.Write(headerBuf)
	return err
}

// ReadMessage はリーダーからメッセージ全体を読み込みます
func ReadMessage(r io.Reader) (*Message, error) {
	header, err := ReadHeader(r)
	if err != nil {
		return nil, err
	}
	
	// ヘッダーの基本的な検証
	if header.MagicNumber != MagicNumber {
		return nil, ErrInvalidMagicNumber
	}
	
	if header.Version != CurrentVersion {
		return nil, ErrInvalidVersion
	}
	
	if header.PayloadLength > uint32(MaxPayloadSize) {
		return nil, ErrPayloadTooLarge
	}
	
	payload := make([]byte, header.PayloadLength)
	if header.PayloadLength > 0 {
		if _, err := io.ReadFull(r, payload); err != nil {
			return nil, err
		}
	}
	
	return &Message{
		Header:  header,
		Payload: payload,
	}, nil
}

// WriteMessage はメッセージをライターに書き込みます
func WriteMessage(w io.Writer, m *Message) error {
	if err := WriteHeader(w, m.Header); err != nil {
		return err
	}
	
	if m.Header.PayloadLength > 0 {
		_, err := w.Write(m.Payload)
		return err
	}
	
	return nil
}
```

### バイナリプロトコルクライアント/サーバー実装例

以下は、実際の業務で使用できるバイナリプロトコルのクライアント/サーバー実装例です：

```go
// client.go
package myprotocol

import (
	"context"
	"fmt"
	"net"
	"sync"
	"time"
)

// Client はプロトコルクライアントを表します
type Client struct {
	conn      net.Conn
	timeout   time.Duration
	mu        sync.Mutex
	connected bool
}

// NewClient は新しいクライアントを作成します
func NewClient(address string, timeout time.Duration) (*Client, error) {
	dialer := net.Dialer{Timeout: timeout}
	conn, err := dialer.Dial("tcp", address)
	if err != nil {
		return nil, fmt.Errorf("接続エラー: %w", err)
	}
	
	return &Client{
		conn:      conn,
		timeout:   timeout,
		connected: true,
	}, nil
}

// Send はメッセージを送信し、レスポンスを待ちます
func (c *Client) Send(ctx context.Context, msgType uint8, payload []byte) (*Message, error) {
	c.mu.Lock()
	defer c.mu.Unlock()
	
	if !c.connected {
		return nil, fmt.Errorf("クライアントは接続されていません")
	}
	
	// コンテキストからのタイムアウト/キャンセル処理
	if ctx != nil {
		if deadline, ok := ctx.Deadline(); ok {
			if err := c.conn.SetDeadline(deadline); err != nil {
				return nil, fmt.Errorf("デッドライン設定エラー: %w", err)
			}
		}
		
		// コンテキストがキャンセルされたかチェック
		select {
		case <-ctx.Done():
			return nil, ctx.Err()
		default:
			// 続行
		}
	}
	
	// メッセージの作成と送信
	msg, err := NewMessage(msgType, payload)
	if err != nil {
		return nil, err
	}
	
	if err := WriteMessage(c.conn, msg); err != nil {
		c.connected = false
		return nil, fmt.Errorf("メッセージ送信エラー: %w", err)
	}
	
	// レスポンスの読み取り
	response, err := ReadMessage(c.conn)
	if err != nil {
		c.connected = false
		return nil, fmt.Errorf("レスポンス読み取りエラー: %w", err)
	}
	
	// エラーレスポンスの処理
	if response.Header.MessageType == TypeError {
		code, message, err := response.ErrorInfo()
		if err != nil {
			return nil, fmt.Errorf("エラーメッセージ解析失敗: %w", err)
		}
		return nil, fmt.Errorf("サーバーエラー: コード=%d, メッセージ=%s", code, message)
	}
	
	return response, nil
}

// Close はクライアント接続を閉じます
func (c *Client) Close() error {
	c.mu.Lock()
	defer c.mu.Unlock()
	
	if !c.connected {
		return nil
	}
	
	c.connected = false
	return c.conn.Close()
}
```

```go
// server.go
package myprotocol

import (
	"context"
	"errors"
	"fmt"
	"log"
	"net"
	"sync"
	"time"
)

// RequestHandler はクライアントリクエストを処理する関数型です
type RequestHandler func(ctx context.Context, msgType uint8, payload []byte) (respType uint8, respPayload []byte, err error)

// Server はプロトコルサーバーを表します
type Server struct {
	listener   net.Listener
	handler    RequestHandler
	ctx        context.Context
	cancelFunc context.CancelFunc
	wg         sync.WaitGroup
	readTimeout  time.Duration
	writeTimeout time.Duration
}

// NewServer は新しいサーバーを作成します
func NewServer(address string, handler RequestHandler, readTimeout, writeTimeout time.Duration) (*Server, error) {
	listener, err := net.Listen("tcp", address)
	if err != nil {
		return nil, fmt.Errorf("リスニングエラー: %w", err)
	}
	
	ctx, cancel := context.WithCancel(context.Background())
	
	return &Server{
		listener:     listener,
		handler:      handler,
		ctx:          ctx,
		cancelFunc:   cancel,
		readTimeout:  readTimeout,
		writeTimeout: writeTimeout,
	}, nil
}

// Start はサーバーを開始します
func (s *Server) Start() {
	s.wg.Add(1)
	go func() {
		defer s.wg.Done()
		s.acceptLoop()
	}()
	log.Printf("サーバーが %s で起動しました", s.listener.Addr())
}

// Stop はサーバーを停止します
func (s *Server) Stop() error {
	s.cancelFunc()
	err := s.listener.Close()
	s.wg.Wait()
	return err
}

// acceptLoop は接続を受け入れるループを実行します
func (s *Server) acceptLoop() {
	for {
		conn, err := s.listener.Accept()
		if err != nil {
			select {
			case <-s.ctx.Done():
				// 正常なシャットダウン
				return
			default:
				log.Printf("接続受け入れエラー: %v", err)
				continue
			}
		}
		
		s.wg.Add(1)
		go func() {
			defer s.wg.Done()
			s.handleConnection(conn)
		}()
	}
}

// handleConnection は1つのクライアント接続を処理します
func (s *Server) handleConnection(conn net.Conn) {
	defer conn.Close()
	log.Printf("クライアント %s から接続を受け入れました", conn.RemoteAddr())
	
	for {
		// コンテキストをチェック
		select {
		case <-s.ctx.Done():
			return
		default:
			// 続行
		}
		
		// 読み取りタイムアウトの設定
		if s.readTimeout > 0 {
			if err := conn.SetReadDeadline(time.Now().Add(s.readTimeout)); err != nil {
				log.Printf("読み取りデッドライン設定エラー: %v", err)
				return
			}
		}
		
		// メッセージの読み取り
		msg, err := ReadMessage(conn)
		if err != nil {
			if errors.Is(err, ErrInvalidMagicNumber) || errors.Is(err, ErrInvalidVersion) {
				// プロトコルエラー、エラーメッセージを送信
				errMsg, _ := NewErrorMessage(ErrCodeInvalidProtocol, err.Error())
				WriteMessage(conn, errMsg)
			}
			
			if netErr, ok := err.(net.Error); ok && netErr.Timeout() {
				log.Printf("クライアント %s からの読み取りタイムアウト", conn.RemoteAddr())
			} else if !errors.Is(err, net.ErrClosed) {
				log.Printf("クライアント %s からの読み取りエラー: %v", conn.RemoteAddr(), err)
			}
			return
		}
		
		// リクエスト処理のためのコンテキスト作成
		reqCtx, cancelReq := context.WithTimeout(s.ctx, s.readTimeout)
		respType, respPayload, err := s.handler(reqCtx, msg.Header.MessageType, msg.Payload)
		cancelReq()
		
		// 書き込みタイムアウトの設定
		if s.writeTimeout > 0 {
			if err := conn.SetWriteDeadline(time.Now().Add(s.writeTimeout)); err != nil {
				log.Printf("書き込みデッドライン設定エラー: %v", err)
				return
			}
		}
		
		// エラー処理とレスポンス送信
		var response *Message
		if err != nil {
			log.Printf("リクエスト処理エラー: %v", err)
			response, _ = NewErrorMessage(ErrCodeServerError, err.Error())
		} else {
			response, err = NewMessage(respType, respPayload)
			if err != nil {
				log.Printf("レスポンス作成エラー: %v", err)
				response, _ = NewErrorMessage(ErrCodeServerError, "内部サーバーエラー")
			}
		}
		
		if err := WriteMessage(conn, response); err != nil {
			log.Printf("クライアント %s への書き込みエラー: %v", conn.RemoteAddr(), err)
			return
		}
	}
}
```

```go
// example.go
package main

import (
	"context"
	"fmt"
	"log"
	"time"
	
	"example.com/myapp/myprotocol"
)

func main() {
	// サーバーハンドラー
	handler := func(ctx context.Context, msgType uint8, payload []byte) (uint8, []byte, error) {
		switch msgType {
		case myprotocol.TypeAuthRequest:
			// 認証処理を実装
			return myprotocol.TypeAuthResponse, []byte("認証成功"), nil
		case myprotocol.TypeDataRequest:
			// データ処理を実装
			return myprotocol.TypeDataResponse, []byte("データ処理完了"), nil
		default:
			return 0, nil, fmt.Errorf("未対応のメッセージタイプ: %d", msgType)
		}
	}
	
	// サーバー起動
	server, err := myprotocol.NewServer(":8080", handler, 5*time.Second, 5*time.Second)
	if err != nil {
		log.Fatalf("サーバー作成エラー: %v", err)
	}
	server.Start()
	defer server.Stop()
	
	// クライアント接続
	client, err := myprotocol.NewClient("localhost:8080", 5*time.Second)
	if err != nil {
		log.Fatalf("クライアント接続エラー: %v", err)
	}
	defer client.Close()
	
	// 認証リクエスト送信
	ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
	defer cancel()
	
	resp, err := client.Send(ctx, myprotocol.TypeAuthRequest, []byte("username:password"))
	if err != nil {
		log.Fatalf("リクエスト送信エラー: %v", err)
	}
	
	fmt.Printf("応答: タイプ=%d, ペイロード=%s\n", resp.Header.MessageType, string(resp.Payload))
}
```

## 3. テキストベースプロトコルの実装

テキストベースプロトコルは可読性が高く、デバッグが容易であるという利点があります。

### テキストプロトコルの設計原則

1. **明確な構文**：コマンドとデータの区別を明確にする
2. **行区切り**：一般的に行ごとにコマンドを区切る（\r\n）
3. **エスケープ処理**：特殊文字の扱いを決める
4. **文字エンコーディング**：UTF-8が標準的

### 行ベースプロトコルの実装例

```go
// textprotocol.go
package textprotocol

import (
	"bufio"
	"errors"
	"fmt"
	"io"
	"strings"
	"sync"
)

const (
	// プロトコル定数
	MaxLineLength = 8192 // 最大8KBの行長
	NewLine       = "\r\n"
)

// CommandType はコマンドの種類を表します
type CommandType string

// 定義されたコマンド
const (
	CmdHELLO CommandType = "HELLO"
	CmdAUTH  CommandType = "AUTH"
	CmdSEND  CommandType = "SEND"
	CmdQUIT  CommandType = "QUIT"
	CmdERROR CommandType = "ERROR"
	CmdOK    CommandType = "OK"
)

// Command はプロトコルコマンドを表します
type Command struct {
	Type   CommandType
	Args   []string
	Data   string
	HasData bool
}

// String はコマンドを文字列に変換します
func (c Command) String() string {
	cmd := string(c.Type)
	if len(c.Args) > 0 {
		cmd += " " + strings.Join(c.Args, " ")
	}
	if c.HasData {
		cmd += " DATA" + NewLine + c.Data + NewLine + "."
	}
	return cmd + NewLine
}

// Parser はプロトコルパーサーを表します
type Parser struct {
	reader *bufio.Reader
	writer *bufio.Writer
	mu     sync.Mutex
}

// NewParser は新しいパーサーを作成します
func NewParser(rw io.ReadWriter) *Parser {
	return &Parser{
		reader: bufio.NewReader(rw),
		writer: bufio.NewWriter(rw),
	}
}

// ReadCommand はクライアントからコマンドを読み取ります
func (p *Parser) ReadCommand() (Command, error) {
	// 最大行長のチェック
	line, err := p.reader.ReadString('\n')
	if err != nil {
		return Command{}, err
	}
	
	if len(line) > MaxLineLength {
		return Command{}, errors.New("行が長すぎます")
	}
	
	// 末尾の改行を削除
	line = strings.TrimSuffix(line, NewLine)
	line = strings.TrimSuffix(line, "\n") // 単一の \n も処理
	
	// 空の行をスキップ
	if line == "" {
		return Command{}, errors.New("空の行")
	}
	
	// コマンドをトークンに分割
	tokens := strings.Fields(line)
	if len(tokens) == 0 {
		return Command{}, errors.New("空のコマンド")
	}
	
	cmd := Command{
		Type: CommandType(strings.ToUpper(tokens[0])),
		Args: []string{},
	}
	
	// DATAフラグをチェック
	hasData := false
	if len(tokens) > 1 {
		cmd.Args = tokens[1:]
		lastArg := tokens[len(tokens)-1]
		if lastArg == "DATA" {
			hasData = true
			// DATA引数を削除
			cmd.Args = cmd.Args[:len(cmd.Args)-1]
		}
	}
	
	// データセクションを読み取る
	if hasData {
		var dataBuilder strings.Builder
		for {
			dataLine, err := p.reader.ReadString('\n')
			if err != nil {
				return Command{}, err
			}
			
			dataLine = strings.TrimSuffix(dataLine, NewLine)
			dataLine = strings.TrimSuffix(dataLine, "\n")
			
			if dataLine == "." {
				break
			}
			
			// エスケープされたドットの処理
			if dataLine == ".." {
				dataLine = "."
			}
			
			dataBuilder.WriteString(dataLine)
			dataBuilder.WriteString("\n")
		}
		
		cmd.Data = dataBuilder.String()
		cmd.HasData = true
	}
	
	return cmd, nil
}

// WriteCommand はコマンドをクライアントに書き込みます
func (p *Parser) WriteCommand(cmd Command) error {
	p.mu.Lock()
	defer p.mu.Unlock()
	
	if _, err := p.writer.WriteString(cmd.String()); err != nil {
		return err
	}
	
	return p.writer.Flush()
}

// WriteOK は成功レスポンスを送信します
func (p *Parser) WriteOK(message string) error {
	args := []string{}
	if message != "" {
		args = []string{message}
	}
	
	return p.WriteCommand(Command{
		Type: CmdOK,
		Args: args,
	})
}

// WriteError はエラーレスポンスを送信します
func (p *Parser) WriteError(code int, message string) error {
	return p.WriteCommand(Command{
		Type: CmdERROR,
		Args: []string{fmt.Sprintf("%d", code), message},
	})
}
```

### テキストプロトコルのクライアント/サーバー実装

```go
// text_server.go
package textprotocol

import (
	"context"
	"fmt"
	"log"
	"net"
	"sync"
	"time"
)

// Handler はコマンドハンドラの関数型です
type Handler func(ctx context.Context, cmd Command) (Command, error)

// Server はテキストプロトコルサーバーを表します
type Server struct {
	listener     net.Listener
	handlers     map[CommandType]Handler
	defaultHandler Handler
	ctx          context.Context
	cancelFunc   context.CancelFunc
	wg           sync.WaitGroup
	readTimeout  time.Duration
	writeTimeout time.Duration
}

// NewServer は新しいサーバーを作成します
func NewServer(address string, readTimeout, writeTimeout time.Duration) (*Server, error) {
	listener, err := net.Listen("tcp", address)
	if err != nil {
		return nil, fmt.Errorf("リスニングエラー: %w", err)
	}
	
	ctx, cancel := context.WithCancel(context.Background())
	
	return &Server{
		listener:     listener,
		handlers:     make(map[CommandType]Handler),
		ctx:          ctx,
		cancelFunc:   cancel,
		readTimeout:  readTimeout,
		writeTimeout: writeTimeout,
	}, nil
}

// RegisterHandler はコマンドタイプに対するハンドラを登録します
func (s *Server) RegisterHandler(cmdType CommandType, handler Handler) {
	s.handlers[cmdType] = handler
}

// SetDefaultHandler はデフォルトハンドラを設定します
func (s *Server) SetDefaultHandler(handler Handler) {
	s.defaultHandler = handler
}

// Start はサーバーを開始します
func (s *Server) Start() {
	s.wg.Add(1)
	go func() {
		defer s.wg.Done()
		s.acceptLoop()
	}()
	log.Printf("テキストプロトコルサーバーが %s で起動しました", s.listener.Addr())
}

// Stop はサーバーを停止します
func (s *Server) Stop() error {
	s.cancelFunc()
	err := s.listener.Close()
	s.wg.Wait()
	return err
}

// acceptLoop は接続受け入れループを実行します
func (s *Server) acceptLoop() {
	for {
		conn, err := s.listener.Accept()
		if err != nil {
			select {
			case <-s.ctx.Done():
				// 正常なシャットダウン
				return
			default:
				log.Printf("接続受け入れエラー: %v", err)
				continue
			}
		}
		
		s.wg.Add(1)
		go func() {
			defer s.wg.Done()
			s.handleConnection(conn)
		}()
	}
}

// handleConnection は1つのクライアント接続を処理します
func (s *Server) handleConnection(conn net.Conn) {
	defer conn.Close()
	log.Printf("クライアント %s から接続を受け入れました", conn.RemoteAddr())
	
	parser := NewParser(conn)
	
	// ウェルカムメッセージの送信
	if err := parser.WriteOK("テキストプロトコルサーバーへようこそ"); err != nil {
		log.Printf("ウェルカムメッセージ送信エラー: %v", err)
		return
	}
	
	for {
		// コンテキストをチェック
		select {
		case <-s.ctx.Done():
			return
		default:
			// 続行
		}
		
		// 読み取りタイムアウトの設定
		if s.readTimeout > 0 {
			if err := conn.SetReadDeadline(time.Now().Add(s.readTimeout)); err != nil {
				log.Printf("読み取りデッドライン設定エラー: %v", err)
				return
			}
		}
		
		// コマンドの読み取り
		cmd, err := parser.ReadCommand()
		if err != nil {
			log.Printf("コマンド読み取りエラー: %v", err)
			return
		}
		
		// QUITコマンドの特別処理
		if cmd.Type == CmdQUIT {
			_ = parser.WriteOK("接続を終了します")
			return
		}
		
		// リクエスト処理のためのコンテキスト作成
		reqCtx, cancelReq := context.WithTimeout(s.ctx, s.readTimeout)
		
		// ハンドラの検索と実行
		handler, ok := s.handlers[cmd.Type]
		if !ok {
			handler = s.defaultHandler
			if handler == nil {
				_ = parser.WriteError(500, fmt.Sprintf("未対応のコマンド: %s", cmd.Type))
				cancelReq()
				continue
			}
		}
		
		resp, err := handler(reqCtx, cmd)
		cancelReq()
		
		// 書き込みタイムアウトの設定
		if s.writeTimeout > 0 {
			if err := conn.SetWriteDeadline(time.Now().Add(s.writeTimeout)); err != nil {
				log.Printf("書き込みデッドライン設定エラー: %v", err)
				return
			}
		}
		
		// レスポンス送信
		if err != nil {
			_ = parser.WriteError(500, err.Error())
		} else {
			if err := parser.WriteCommand(resp); err != nil {
				log.Printf("レスポンス送信エラー: %v", err)
				return
			}
		}
	}
}
```

```go
// text_client.go
package textprotocol

import (
	"context"
	"fmt"
	"net"
	"sync"
	"time"
)

// Client はテキストプロトコルクライアントを表します
type Client struct {
	conn      net.Conn
	parser    *Parser
	mu        sync.Mutex
	connected bool
	timeout   time.Duration
}

// NewClient は新しいクライアントを作成します
func NewClient(address string, timeout time.Duration) (*Client, error) {
	dialer := net.Dialer{Timeout: timeout}
	conn, err := dialer.Dial("tcp", address)
	if err != nil {
		return nil, fmt.Errorf("接続エラー: %w", err)
	}
	
	parser := NewParser(conn)
	
	// ウェルカムメッセージの読み取り
	if err := conn.SetReadDeadline(time.Now().Add(timeout)); err != nil {
		conn.Close()
		return nil, fmt.Errorf("デッドライン設定エラー: %w", err)
	}
	
	cmd, err := parser.ReadCommand()
	if err != nil {
		conn.Close()
		return nil, fmt.Errorf("ウェルカムメッセージ読み取りエラー: %w", err)
	}
	
	if cmd.Type != CmdOK {
		conn.Close()
		return nil, fmt.Errorf("予期しないレスポンス: %s", cmd.Type)
	}
	
	return &Client{
		conn:      conn,
		parser:    parser,
		connected: true,
		timeout:   timeout,
	}, nil
}

// Send はコマンドを送信し、レスポンスを待ちます
func (c *Client) Send(ctx context.Context, cmd Command) (Command, error) {
	c.mu.Lock()
	defer c.mu.Unlock()
	
	if !c.connected {
		return Command{}, fmt.Errorf("クライアントは接続されていません")
	}
	
	// コンテキストからのタイムアウト/キャンセル処理
	if ctx != nil {
		if deadline, ok := ctx.Deadline(); ok {
			if err := c.conn.SetDeadline(deadline); err != nil {
				return Command{}, fmt.Errorf("デッドライン設定エラー: %w", err)
			}
		}
		
		// コンテキストがキャンセルされたかチェック
		select {
		case <-ctx.Done():
			return Command{}, ctx.Err()
		default:
			// 続行
		}
	}
	
	// コマンドの送信
	if err := c.parser.WriteCommand(cmd); err != nil {
		c.connected = false
		return Command{}, fmt.Errorf("コマンド送信エラー: %w", err)
	}
	
	// レスポンスの読み取り
	resp, err := c.parser.ReadCommand()
	if err != nil {
		c.connected = false
		return Command{}, fmt.Errorf("レスポンス読み取りエラー: %w", err)
	}
	
	// エラーレスポンスの処理
	if resp.Type == CmdERROR {
		if len(resp.Args) >= 2 {
			return Command{}, fmt.Errorf("サーバーエラー: コード=%s, メッセージ=%s", resp.Args[0], resp.Args[1])
		}
		return Command{}, fmt.Errorf("サーバーエラー: %v", resp.Args)
	}
	
	return resp, nil
}

// Close はクライアント接続を閉じます
func (c *Client) Close() error {
	c.mu.Lock()
	defer c.mu.Unlock()
	
	if !c.connected {
		return nil
	}
	
	// QUITコマンドを送信
	_ = c.parser.WriteCommand(Command{
		Type: CmdQUIT,
	})
	
	c.connected = false
	return c.conn.Close()
}
```

## 4. シリアライゼーション（JSON, Protocol Buffers, gob）

データシリアライゼーションは、構造化データを送受信するための重要な技術です。Goでは複数のシリアライゼーション形式をサポートしています。

### JSON実装

JSONは広く使用されるテキストベースのシリアライゼーション形式です：

```go
// json_serialization.go
package serialization

import (
	"bytes"
	"encoding/json"
	"io"
	"time"
)

// User はユーザー情報を表します
type User struct {
	ID        int64     `json:"id"`
	Username  string    `json:"username"`
	Email     string    `json:"email,omitempty"`
	Active    bool      `json:"active"`
	CreatedAt time.Time `json:"created_at"`
	UpdatedAt time.Time `json:"updated_at"`
	Metadata  any       `json:"metadata,omitempty"`
}

// JSONSerializer はJSONシリアライザーを表します
type JSONSerializer struct {
	// エンコード/デコードオプション
	UseIndent bool
	Indent    string
	Prefix    string
}

// NewJSONSerializer は新しいJSONシリアライザーを作成します
func NewJSONSerializer(useIndent bool, indent, prefix string) *JSONSerializer {
	return &JSONSerializer{
		UseIndent: useIndent,
		Indent:    indent,
		Prefix:    prefix,
	}
}

// Serialize はオブジェクトをJSON文字列にシリアライズします
func (s *JSONSerializer) Serialize(v any) ([]byte, error) {
	buf := new(bytes.Buffer)
	encoder := json.NewEncoder(buf)
	
	if s.UseIndent {
		encoder.SetIndent(s.Prefix, s.Indent)
	}
	
	if err := encoder.Encode(v); err != nil {
		return nil, err
	}
	
	return buf.Bytes(), nil
}

// Deserialize はJSON文字列からオブジェクトにデシリアライズします
func (s *JSONSerializer) Deserialize(data []byte, v any) error {
	decoder := json.NewDecoder(bytes.NewReader(data))
	return decoder.Decode(v)
}

// SerializeToWriter はオブジェクトをJSON形式でライターに書き込みます
func (s *JSONSerializer) SerializeToWriter(w io.Writer, v any) error {
	encoder := json.NewEncoder(w)
	
	if s.UseIndent {
		encoder.SetIndent(s.Prefix, s.Indent)
	}
	
	return encoder.Encode(v)
}

// DeserializeFromReader はリーダーからJSON形式でオブジェクトを読み込みます
func (s *JSONSerializer) DeserializeFromReader(r io.Reader, v any) error {
	decoder := json.NewDecoder(r)
	return decoder.Decode(v)
}
```

```go
// protobuf_serialization.go
package serialization

import (
	"errors"
	"fmt"
	"io"
	"io/ioutil"
	
	"google.golang.org/protobuf/proto"
	"google.golang.org/protobuf/types/known/anypb"
	"google.golang.org/protobuf/types/known/timestamppb"
)

// ProtoSerializer はProtocol Buffersシリアライザーを表します
type ProtoSerializer struct{}

// NewProtoSerializer は新しいProtocol Buffersシリアライザーを作成します
func NewProtoSerializer() *ProtoSerializer {
	return &ProtoSerializer{}
}

// Serialize はオブジェクトをProtoBufバイナリにシリアライズします
func (s *ProtoSerializer) Serialize(v proto.Message) ([]byte, error) {
	return proto.Marshal(v)
}

// Deserialize はProtoBufバイナリからオブジェクトにデシリアライズします
func (s *ProtoSerializer) Deserialize(data []byte, v proto.Message) error {
	return proto.Unmarshal(data, v)
}

// SerializeToWriter はオブジェクトをProtoBuf形式でライターに書き込みます
func (s *ProtoSerializer) SerializeToWriter(w io.Writer, v proto.Message) error {
	data, err := proto.Marshal(v)
	if err != nil {
		return err
	}
	
	_, err = w.Write(data)
	return err
}

// DeserializeFromReader はリーダーからProtoBuf形式でオブジェクトを読み込みます
func (s *ProtoSerializer) DeserializeFromReader(r io.Reader, v proto.Message) error {
	data, err := ioutil.ReadAll(r)
	if err != nil {
		return err
	}
	
	return proto.Unmarshal(data, v)
}

// ConvertUserToProto はGoのUserをProtoのUserに変換します
func ConvertUserToProto(user User) (*UserProto, error) {
	metadata, err := anypb.New(&anypb.Any{})
	if err != nil {
		return nil, err
	}
	
	return &UserProto{
		Id:        user.ID,
		Username:  user.Username,
		Email:     user.Email,
		Active:    user.Active,
		CreatedAt: timestamppb.New(user.CreatedAt),
		UpdatedAt: timestamppb.New(user.UpdatedAt),
		Metadata:  metadata,
	}, nil
}

// ConvertProtoToUser はProtoのUserをGoのUserに変換します
func ConvertProtoToUser(userProto *UserProto) (User, error) {
	if userProto == nil {
		return User{}, errors.New("プロトメッセージがnilです")
	}
	
	return User{
		ID:        userProto.Id,
		Username:  userProto.Username,
		Email:     userProto.Email,
		Active:    userProto.Active,
		CreatedAt: userProto.CreatedAt.AsTime(),
		UpdatedAt: userProto.UpdatedAt.AsTime(),

	}, nil
}
```

## 5. パケット構造と解析

パケット構造と解析は、カスタムプロトコルの実装において重要な要素です。

### パケットフレーミング手法

フレーミングはパケットの境界を定義する方法で、以下の手法があります：

1. **長さプレフィックス**：パケットの前にデータ長を付加
2. **デリミタベース**：特殊文字でパケットを区切る
3. **固定長**：すべてのパケットが同じ長さ
4. **TLV (Type-Length-Value)**：型、長さ、値の3要素で構成

### パケットフレーミングとパーサーの実装

```go
// packet.go
package packet

import (
	"bytes"
	"encoding/binary"
	"errors"
	"fmt"
	"hash/crc32"
	"io"
)

const (
	// マジックバイトとバージョン
	Magic      uint16 = 0xCAFE
	Version    uint8  = 0x01
	HeaderSize        = 12
	
	// 最大パケットサイズ
	MaxPacketSize = 10 * 1024 * 1024 // 10MB
)

// パケットタイプ
const (
	TypeRequest  uint8 = 0x01
	TypeResponse uint8 = 0x02
	TypeNotify   uint8 = 0x03
	TypePing     uint8 = 0x04
	TypePong     uint8 = 0x05
	TypeError    uint8 = 0xFF
)

// エラー定義
var (
	ErrInvalidMagic    = errors.New("無効なマジックナンバー")
	ErrInvalidVersion  = errors.New("サポートされていないバージョン")
	ErrPacketTooLarge  = errors.New("パケットサイズが最大値を超えています")
	ErrInvalidChecksum = errors.New("チェックサムが一致しません")
	ErrIncompleteRead  = errors.New("パケットの読み取りが不完全です")
	ErrInvalidType     = errors.New("無効なパケットタイプ")
)

// Header はパケットヘッダーを表します
type Header struct {
	Magic      uint16
	Version    uint8
	Type       uint8
	Length     uint32
	Sequence   uint16
	Checksum   uint32
}

// Packet はパケット全体を表します
type Packet struct {
	Header  Header
	Payload []byte
}

// NewPacket は新しいパケットを作成します
func NewPacket(packetType uint8, sequence uint16, payload []byte) (*Packet, error) {
	if len(payload) > MaxPacketSize-HeaderSize {
		return nil, ErrPacketTooLarge
	}
	
	// パケットの作成
	p := &Packet{
		Header: Header{
			Magic:      Magic,
			Version:    Version,
			Type:       packetType,
			Length:     uint32(HeaderSize + len(payload)),
			Sequence:   sequence,
			Checksum:   0, // 一時的に0を設定
		},
		Payload: payload,
	}
	
	// チェックサムの計算と設定
	p.Header.Checksum = p.CalculateChecksum()
	
	return p, nil
}

// CalculateChecksum はパケットのチェックサムを計算します
func (p *Packet) CalculateChecksum() uint32 {
	// ヘッダーをバイトに変換（チェックサムフィールドは0に設定）
	header := p.Header
	header.Checksum = 0
	
	var buf bytes.Buffer
	binary.Write(&buf, binary.BigEndian, header.Magic)
	binary.Write(&buf, binary.BigEndian, header.Version)
	binary.Write(&buf, binary.BigEndian, header.Type)
	binary.Write(&buf, binary.BigEndian, header.Length)
	binary.Write(&buf, binary.BigEndian, header.Sequence)
	binary.Write(&buf, binary.BigEndian, header.Checksum)
	
	// ペイロードを追加
	buf.Write(p.Payload)
	
	// CRC32チェックサムを計算
	return crc32.ChecksumIEEE(buf.Bytes())
}

// Validate はパケットを検証します
func (p *Packet) Validate() error {
	if p.Header.Magic != Magic {
		return ErrInvalidMagic
	}
	
	if p.Header.Version != Version {
		return ErrInvalidVersion
	}
	
	if p.Header.Length > MaxPacketSize {
		return ErrPacketTooLarge
	}
	
	switch p.Header.Type {
	case TypeRequest, TypeResponse, TypeNotify, TypePing, TypePong, TypeError:
		// 有効なパケットタイプ
	default:
		return ErrInvalidType
	}
	
	expectedChecksum := p.CalculateChecksum()
	if p.Header.Checksum != expectedChecksum {
		return ErrInvalidChecksum
	}
	
	return nil
}

// PacketReader はパケットリーダーを表します
type PacketReader struct {
	reader io.Reader
	buffer bytes.Buffer
}

// NewPacketReader は新しいパケットリーダーを作成します
func NewPacketReader(r io.Reader) *PacketReader {
	return &PacketReader{
		reader: r,
	}
}

// ReadPacket はパケットを読み取ります
func (pr *PacketReader) ReadPacket() (*Packet, error) {
	// ヘッダーを読み取り
	headerBuf := make([]byte, HeaderSize)
	_, err := io.ReadFull(pr.reader, headerBuf)
	if err != nil {
		return nil, fmt.Errorf("ヘッダー読み取りエラー: %w", err)
	}
	
	bufReader := bytes.NewReader(headerBuf)
	
	var header Header
	err = binary.Read(bufReader, binary.BigEndian, &header)
	if err != nil {
		return nil, fmt.Errorf("ヘッダーのデコードエラー: %w", err)
	}
	
	// ヘッダーの基本検証
	if header.Magic != Magic {
		return nil, ErrInvalidMagic
	}
	
	if header.Version != Version {
		return nil, ErrInvalidVersion
	}
	
	if header.Length > MaxPacketSize {
		return nil, ErrPacketTooLarge
	}
	
	if header.Length < HeaderSize {
		return nil, fmt.Errorf("無効なパケット長: %d", header.Length)
	}
	
	// ペイロードの読み取り
	payloadSize := header.Length - HeaderSize
	payload := make([]byte, payloadSize)
	
	if payloadSize > 0 {
		_, err = io.ReadFull(pr.reader, payload)
		if err != nil {
			return nil, fmt.Errorf("ペイロード読み取りエラー: %w", err)
		}
	}
	
	packet := &Packet{
		Header:  header,
		Payload: payload,
	}
	
	// チェックサムの検証
	expectedChecksum := packet.CalculateChecksum()
	if packet.Header.Checksum != expectedChecksum {
		return nil, ErrInvalidChecksum
	}
	
	return packet, nil
}

// PacketWriter はパケットライターを表します
type PacketWriter struct {
	writer io.Writer
}

// NewPacketWriter は新しいパケットライターを作成します
func NewPacketWriter(w io.Writer) *PacketWriter {
	return &PacketWriter{
		writer: w,
	}
}

// WritePacket はパケットを書き込みます
func (pw *PacketWriter) WritePacket(p *Packet) error {
	var buf bytes.Buffer
	
	// ヘッダーを書き込み
	err := binary.Write(&buf, binary.BigEndian, p.Header)
	if err != nil {
		return fmt.Errorf("ヘッダーのエンコードエラー: %w", err)
	}
	
	// ペイロードを書き込み
	_, err = buf.Write(p.Payload)
	if err != nil {
		return fmt.Errorf("ペイロードの書き込みエラー: %w", err)
	}
	
	// ライターに書き込み
	_, err = pw.writer.Write(buf.Bytes())
	if err != nil {
		return fmt.Errorf("パケットの書き込みエラー: %w", err)
	}
	
	return nil
}
```

### フレームベースのプロトコル実装

```go
// frame_protocol.go
package packet

import (
	"bufio"
	"bytes"
	"encoding/binary"
	"errors"
	"fmt"
	"io"
	"net"
	"sync"
	"sync/atomic"
	"time"
)

// デリミタベースのプロトコル定数
const (
	StartMarker  = 0x02 // STX (Start of Text)
	EndMarker    = 0x03 // ETX (End of Text)
	EscapeMarker = 0x1B // ESC (Escape)
	MaxFrameSize = 1024 * 1024 // 1MB
)

// FrameProtocol はフレームベースのプロトコルを表します
type FrameProtocol struct {
	conn         net.Conn
	reader       *bufio.Reader
	writer       *bufio.Writer
	readTimeout  time.Duration
	writeTimeout time.Duration
	sequenceID   uint32
	mu           sync.Mutex
}

// NewFrameProtocol は新しいフレームプロトコルインスタンスを作成します
func NewFrameProtocol(conn net.Conn, readTimeout, writeTimeout time.Duration) *FrameProtocol {
	return &FrameProtocol{
		conn:         conn,
		reader:       bufio.NewReader(conn),
		writer:       bufio.NewWriter(conn),
		readTimeout:  readTimeout,
		writeTimeout: writeTimeout,
	}
}

// SendFrame はフレームを送信します
func (fp *FrameProtocol) SendFrame(frameType uint8, payload []byte) error {
	fp.mu.Lock()
	defer fp.mu.Unlock()
	
	// 書き込みタイムアウトの設定
	if fp.writeTimeout > 0 {
		if err := fp.conn.SetWriteDeadline(time.Now().Add(fp.writeTimeout)); err != nil {
			return fmt.Errorf("書き込みデッドライン設定エラー: %w", err)
		}
	}
	
	// シーケンスIDの増加
	seq := atomic.AddUint32(&fp.sequenceID, 1)
	
	// パケットの作成
	packet, err := NewPacket(frameType, uint16(seq), payload)
	if err != nil {
		return err
	}
	
	// バッファにパケットを書き込み
	var buf bytes.Buffer
	buf.WriteByte(StartMarker)
	
	// パケットをバイト列に変換
	var packetBuf bytes.Buffer
	pw := NewPacketWriter(&packetBuf)
	if err := pw.WritePacket(packet); err != nil {
		return err
	}
	
	// パケットデータのエスケープ処理
	packetBytes := packetBuf.Bytes()
	for _, b := range packetBytes {
		switch b {
		case StartMarker, EndMarker, EscapeMarker:
			buf.WriteByte(EscapeMarker)
			buf.WriteByte(b)
		default:
			buf.WriteByte(b)
		}
	}
	
	buf.WriteByte(EndMarker)
	
	// フレームの送信
	_, err = fp.writer.Write(buf.Bytes())
	if err != nil {
		return fmt.Errorf("フレーム書き込みエラー: %w", err)
	}
	
	return fp.writer.Flush()
}

// ReadFrame はフレームを読み取ります
func (fp *FrameProtocol) ReadFrame() (*Packet, error) {
	// 読み取りタイムアウトの設定
	if fp.readTimeout > 0 {
		if err := fp.conn.SetReadDeadline(time.Now().Add(fp.readTimeout)); err != nil {
			return nil, fmt.Errorf("読み取りデッドライン設定エラー: %w", err)
		}
	}
	
	// スタートマーカーを探す
	startByte, err := fp.reader.ReadByte()
	if err != nil {
		return nil, fmt.Errorf("スタートマーカー読み取りエラー: %w", err)
	}
	
	// スタートマーカーを見つけるまでスキップ
	for startByte != StartMarker {
		startByte, err = fp.reader.ReadByte()
		if err != nil {
			return nil, fmt.Errorf("スタートマーカー検索エラー: %w", err)
		}
	}
	
	// フレームデータを読み取る
	var frameBuffer bytes.Buffer
	escaped := false
	
	for {
		b, err := fp.reader.ReadByte()
		if err != nil {
			return nil, fmt.Errorf("フレームデータ読み取りエラー: %w", err)
		}
		
		if escaped {
			// エスケープされたバイトを処理
			frameBuffer.WriteByte(b)
			escaped = false
			continue
		}
		
		switch b {
		case EscapeMarker:
			escaped = true
		case EndMarker:
			// フレーム終了
			goto FrameComplete
		default:
			frameBuffer.WriteByte(b)
		}
		
		// フレームサイズのチェック
		if frameBuffer.Len() > MaxFrameSize {
			return nil, errors.New("フレームサイズが上限を超えています")
		}
	}
	
FrameComplete:
	// フレームからパケットを解析
	frameData := frameBuffer.Bytes()
	pr := NewPacketReader(bytes.NewReader(frameData))
	packet, err := pr.ReadPacket()
	if err != nil {
		return nil, fmt.Errorf("パケット解析エラー: %w", err)
	}
	
	return packet, nil
}

// Close は接続を閉じます
func (fp *FrameProtocol) Close() error {
	return fp.conn.Close()
}
```

### パケットとフレームの使用例

```go
// frame_example.go
package main

import (
	"context"
	"fmt"
	"log"
	"net"
	"sync"
	"time"
	
	"example.com/myapp/packet"
)

func main() {
	// サーバーの起動
	go startServer()
	time.Sleep(100 * time.Millisecond) // サーバーの起動を待つ
	
	// クライアントの実行
	runClient()
}

func startServer() {
	listener, err := net.Listen("tcp", ":8083")
	if err != nil {
		log.Fatalf("リスニングエラー: %v", err)
	}
	defer listener.Close()
	
	log.Println("フレームプロトコルサーバーが起動しました")
	
	for {
		conn, err := listener.Accept()
		if err != nil {
			log.Printf("接続受け入れエラー: %v", err)
			continue
		}
		
		log.Printf("クライアント %s から接続を受け入れました", conn.RemoteAddr())
		go handleClient(conn)
	}
}

func handleClient(conn net.Conn) {
	defer conn.Close()
	
	fp := packet.NewFrameProtocol(conn, 5*time.Second, 5*time.Second)
	defer fp.Close()
	
	for {
		// フレームの読み取り
		p, err := fp.ReadFrame()
		if err != nil {
			log.Printf("フレーム読み取りエラー: %v", err)
			return
		}
		
		log.Printf("フレーム受信: タイプ=%d, シーケンス=%d, ペイロード=%s",
			p.Header.Type, p.Header.Sequence, string(p.Payload))
		
		// フレームタイプに基づいて処理
		switch p.Header.Type {
		case packet.TypePing:
			// PONGで応答
			err = fp.SendFrame(packet.TypePong, []byte("PONG"))
			
		case packet.TypeRequest:
			// リクエストの処理
			response := fmt.Sprintf("応答: %s", string(p.Payload))
			err = fp.SendFrame(packet.TypeResponse, []byte(response))
			
		case packet.TypeNotify:
			// 通知の処理 (応答は不要)
			log.Printf("通知を受信しました: %s", string(p.Payload))
			continue
			
		default:
			err = fp.SendFrame(TypeError, []byte("サポートされていないフレームタイプ"))
		}
		
		if err != nil {
			log.Printf("フレーム送信エラー: %v", err)
			return
		}
	}
}

func runClient() {
	// サーバーに接続
	conn, err := net.Dial("tcp", "localhost:8083")
	if err != nil {
		log.Fatalf("サーバー接続エラー: %v", err)
	}
	defer conn.Close()
	
	fp := packet.NewFrameProtocol(conn, 5*time.Second, 5*time.Second)
	defer fp.Close()
	
	// 複数のフレームを並行して送信するテスト
	var wg sync.WaitGroup
	ctx, cancel := context.WithTimeout(context.Background(), 10*time.Second)
	defer cancel()
	
	// Pingリクエスト
	wg.Add(1)
	go func() {
		defer wg.Done()
		
		err := fp.SendFrame(packet.TypePing, []byte("PING"))
		if err != nil {
			log.Printf("Ping送信エラー: %v", err)
			return
		}
		
		// 応答の待機
		p, err := fp.ReadFrame()
		if err != nil {
			log.Printf("Pong読み取りエラー: %v", err)
			return
		}
		
		log.Printf("Pong受信: シーケンス=%d, ペイロード=%s", p.Header.Sequence, string(p.Payload))
	}()
	
	// データリクエスト
	wg.Add(1)
	go func() {
		defer wg.Done()
		
		err := fp.SendFrame(packet.TypeRequest, []byte("データリクエスト"))
		if err != nil {
			log.Printf("リクエスト送信エラー: %v", err)
			return
		}
		
		// 応答の待機
		p, err := fp.ReadFrame()
		if err != nil {
			log.Printf("応答読み取りエラー: %v", err)
			return
		}
		
		log.Printf("応答受信: シーケンス=%d, ペイロード=%s", p.Header.Sequence, string(p.Payload))
	}()
	
	// 通知の送信
	wg.Add(1)
	go func() {
		defer wg.Done()
		
		err := fp.SendFrame(packet.TypeNotify, []byte("これは通知です"))
		if err != nil {
			log.Printf("通知送信エラー: %v", err)
			return
		}
		
		log.Printf("通知が送信されました")
	}()
	
	// ゴルーチンの終了を待機（タイムアウト付き）
	done := make(chan struct{})
	go func() {
		wg.Wait()
		close(done)
	}()
	
	select {
	case <-done:
		log.Println("すべてのリクエストが完了しました")
	case <-ctx.Done():
		log.Println("タイムアウト: 一部のリクエストが完了しませんでした")
	}
}
```
